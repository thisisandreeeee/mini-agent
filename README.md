# mini-agent

A barebones Python agent project.

## Setup

Install `uv`:

```sh
curl -LsSf https://astral.sh/uv/install.sh | sh
```

Create the environment and install the project:

```sh
uv sync
```

Run Python inside the environment:

```sh
uv run python
```

Add dependencies later with:

```sh
uv add <package>
```
