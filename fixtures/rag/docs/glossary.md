# Kestrel Glossary of Internal Terms

A quick reference for Kestrel-specific codenames and jargon. Terms are listed
alphabetically.

- **Abyssal** — the highest data-classification tier, used for customer PII.
- **Anchor** — the internal deployment CLI (`anchor ship`, `anchor recall`).
- **Beacon** — the audit trail that logs break-glass access to Abyssal data.
- **Driftwood** — Kestrel's in-house message bus, replacing Kafka since release 5.0.
- **Halyard** — the modified-Raft consensus protocol used by Marlin coordinators.
- **Lantern** — the shared pager account carried by the on-call engineer.
- **Lighthouse** — the weekly on-call rotation.
- **Marlin** — Tidepool's distributed continuous-query engine.
- **Nautilus block** — the columnar storage format used by Reef since ADR-029.
- **Pip** — the company mascot, a kestrel.
- **Reef** — Tidepool's columnar storage layer.
- **Rockpool** — the miniature test cluster used in integration tests.
- **Slack Tide** — the paid 6-week sabbatical after 4 years of service.
- **SLOSH** — a TideQL adaptive session-window function.
- **Tideway** — the name of the main source-control branch.
- **Tidegate** — the ingestion gateway that authenticates and rate-limits producers.
- **Tidewatch** — the canary deployment stage that routes 3% of traffic to new builds.
- **TTFI** — "time to first insight", Kestrel's north-star latency metric.
- **Vaultkeep** — the secret-management service.
- **Wellspring** — the annual $1,800 wellness stipend.
